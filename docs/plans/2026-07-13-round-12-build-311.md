### Gotcha (cost one archive cycle)

First archive FAILED at the "Bundle React Native code and images" phase:
`UnableToResolveError: Unable to resolve module react-native-image-crop-picker from
src/utils/avatar-crop-picker.ts`. The main checkout's `node_modules` was stale — the
merged code added `react-native-image-crop-picker@0.51.1` (avatar-crop feature) but the
package was not installed locally (fast-forwarding the git tree does not install JS deps).
Fix: `yarn install` then re-run `bundle exec pod install` (so New-Arch autolinking +
`RNCImageCropPickerSpec` codegen wire against complete `node_modules`), then re-archive.
Lesson: after fast-forwarding the build checkout, run `yarn install` before `pod install`
whenever `package.json` changed since the last local install.
