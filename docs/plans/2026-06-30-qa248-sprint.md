## Root causes corrected by DB forensics
- **#2 daily-limit block** was NOT stuck rows — the 30-min `autoFixMissingInsights` cron regenerated a QUIZ insight every tick (generated insights had `day_id=NULL`, so the day never registered as filled) until it hit the daily-10 cap and blocked the user. Same loop fired the spurious "Khanh reflected" push each tick.
- **#6 birth time** persists fine (PATCH /me → `User.birthTime`, live-verified `16:53:33`); it was just never entered before. Follow-up: `user_profiles.birth_time` (legacy) stays NULL, out of sync.
- **Bedtime** wasn't generating because the nightly cron counted only takeaway reflections; deep-chat only triggered on milestone days.
